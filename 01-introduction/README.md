# 01 — Introduction

Before we touch a single API, we need to answer a simple question: **what is Shopify, really?**

This section builds the mental foundation everything else in the course rests on. By the end you should be able to explain, to another engineer, what Shopify does, who its users are, and why it is architected the way it is.
