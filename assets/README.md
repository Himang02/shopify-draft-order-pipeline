# Assets

Diagrams and images used by the chapters.

Wherever possible, this course prefers **ASCII diagrams written inline in the chapters** — they render everywhere, diff cleanly in git, and never go stale as broken image links. This folder is for the cases where a raster or vector image genuinely helps (screenshots of the Shopify admin, for instance).

## Conventions

- Name files after the chapter that uses them, e.g. `03-04-draft-order-flow.png`.
- Prefer SVG or PNG.
- Reference them with relative paths from the chapter, e.g. `![...](../assets/03-04-draft-order-flow.png)`.
